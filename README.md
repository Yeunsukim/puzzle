# 🧩 퍼즐 친구들

친구를 초대해서 같이 맞추는 온라인 조각 퍼즐이에요.

## 켜는 방법
처음 한 번만:
```bash
npm install
```
켜기:
```bash
npm start
```
- 이 컴퓨터에서: http://localhost:3000
- 같은 와이파이의 휴대폰·다른 컴퓨터: 서버를 켜면 검은 창에 나오는 `http://10.x.x.x:3000` 같은 주소
  (윈도우가 "방화벽 허용" 창을 띄우면 **허용** 을 눌러 주세요)

## 인터넷에 올리기
멀리 있는 친구도 들어오게 하려면 `인터넷에_올리는_방법.md` 를 따라 Render(서버) + Supabase(데이터베이스)에 올려요.
- `DATABASE_URL` 이 있으면 Supabase에, 없으면 내 컴퓨터의 `data/puzzle.db` 에 저장해요.
- Render 설정은 `render.yaml` 에 들어 있어요.

## 들어 있는 것
- 이메일 가입·로그인, 구글 로그인 (켜는 법: `구글로그인_설정방법.md`)
- 왼쪽 위 메뉴(줄 세 개): 내 정보, 받은 초대·친구 신청, 친구 코드, 로그아웃
- 친구 맺기(이메일 또는 친구 코드) → 퍼즐 방에서 친구에게 초대 보내기 → 친구가 수락하면 같은 방으로
- 작품 그림 4장 + 어린이 그림 4장 + 내 사진 올리기, 조각 수 10 · 24 · 48 · 100 · 300 · 500 · 1000
- 한 방에 6명까지 실시간으로 같이 맞추기, 초대 링크·방 번호
- 작품 그림 다시 만들기: `node scripts/make-art.mjs`
- 완성하면 걸린 시간과 각자 맞춘 조각 수가 "내 기록"에 남아요

## 파일
- `server/` 서버 (회원, 퍼즐 그림, 게임방 실시간 동기화)
- `public/` 화면 (페이지, 퍼즐판, 캐릭터·기본 그림)
- `data/` 가입 정보·기록·올린 사진이 저장되는 곳 (자동으로 생겨요)
